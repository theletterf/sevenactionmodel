---

Claude Code या किसी समर्थित एजेंट के साथ इस कौशल का उपयोग करें ताकि तकनीकी दस्तावेज़ों की योजना, लेखन, समीक्षा और पुनर्संरचना पाठक के लक्ष्य के आधार पर की जा सके।

## Claude Code के लिए स्थापित करें

```sh
npx skills add theletterf/sevenactionmodel --skill seven-action-documentation --agent claude-code
```

हर परियोजना में उपलब्ध कराने के लिए `--global` जोड़ें। यह दस्तावेज़ योजना, लेखन, ऑडिट, सूचना-वास्तुकला और सफलता मापदंडों के लिए सक्रिय होता है; `$seven-action-documentation` से इसे सीधे भी बुलाया जा सकता है।
