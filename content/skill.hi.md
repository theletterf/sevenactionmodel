---

Claude Code या किसी समर्थित एजेंट के साथ इस Skill का उपयोग करें ताकि तकनीकी दस्तावेज़ों की योजना, लेखन, समीक्षा और पुनर्संरचना इस आधार पर की जा सके कि पाठक क्या पूरा करना चाहते हैं।

## Claude Code के लिए स्थापित करें

```sh
npx skills add theletterf/sevenactionmodel \
  --skill seven-action-documentation \
  --agent claude-code
```

हर परियोजना में उपलब्ध कराने के लिए `--global` जोड़ें। यह Skill दस्तावेज़ योजना, लेखन, ऑडिट, सूचना वास्तुकला और सफलता मेट्रिक्स पर काम करते समय सक्रिय होता है। आप इसे सीधे भी बुला सकते हैं:

```text
हमारे ऑनबोर्डिंग दस्तावेज़ों का ऑडिट करने के लिए $seven-action-documentation का उपयोग करें।
```

यह Skill एजेंट को उत्पाद के बारे में तथ्य गढ़े बिना पाठक की मुख्य क्रिया पहचानने, उपयोगी सामग्री प्रकार चुनने और परिणाम तथा उसके माप को परिभाषित करने में मदद करता है।
