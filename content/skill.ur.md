---

اس مہارت کو Claude Code یا کسی معاون ایجنٹ کے ساتھ استعمال کریں تاکہ تکنیکی دستاویزات کی منصوبہ بندی، تحریر، جانچ اور تنظیمِ نو ان کاموں کے گرد کی جا سکے جو قارئین انجام دینا چاہتے ہیں۔

## Claude Code کے لیے تنصیب

```sh
npx skills add theletterf/sevenactionmodel \
  --skill seven-action-documentation \
  --agent claude-code
```

ہر منصوبے میں دستیابی کے لیے `--global` شامل کریں۔ یہ مہارت دستاویزاتی منصوبہ بندی، تحریر، آڈٹ، معلوماتی ساخت اور کامیابی کے پیمانوں پر کام کرتے وقت خودکار طور پر فعال ہوتی ہے۔ اسے براہ راست بھی بلایا جا سکتا ہے:

```text
ہماری ابتدائی رہنمائی کی دستاویزات کا آڈٹ کرنے کے لیے $seven-action-documentation استعمال کریں۔
```

یہ مہارت مصنوعات کے بارے میں حقائق گھڑے بغیر ایجنٹ کو قاری کا بنیادی عمل شناخت کرنے، مفید مواد کی اقسام چننے اور نتیجہ اور اس کا پیمانہ متعین کرنے میں مدد دیتی ہے۔
