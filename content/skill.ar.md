description: "ثبّت Skill وكيل لتخطيط الوثائق وتحسينها باستخدام نموذج الإجراءات السبعة."
---

استخدم هذا الـSkill مع Claude Code أو أي وكيل مدعوم لتخطيط الوثائق التقنية وكتابتها ومراجعتها وإعادة تنظيمها حول ما يحتاج القراء إلى إنجازه.

## التثبيت لـ Claude Code

```sh
npx skills add theletterf/sevenactionmodel \
  --skill seven-action-documentation \
  --agent claude-code
```

أضف `--global` لإتاحته في كل مشروع. يُفعَّل الـSkill عند تخطيط الوثائق وكتابتها وتدقيقها وتصميم بنية المعلومات ومقاييس النجاح. ويمكنك أيضاً استدعاؤها مباشرةً:

```text
استخدم $seven-action-documentation لتدقيق وثائق إعداد المستخدمين لدينا.
```

يساعد الـSkill الوكيل على تحديد الإجراء الرئيسي للقارئ، واختيار أنواع محتوى مفيدة، وتعريف نتيجة ومقياس من دون اختلاق حقائق عن المنتج.
