Используйте этот skill с Claude Code или другим совместимым агентом, чтобы планировать, писать, проверять и перестраивать техническую документацию вокруг того, чего читатели должны с её помощью достичь.

## Установка для Claude Code

```sh
npx skills add theletterf/sevenactionmodel \
  --skill seven-action-documentation \
  --agent claude-code
```

Добавьте `--global`, чтобы skill был доступен во всех проектах. Он активируется при планировании и написании документации, аудите, проектировании информационной архитектуры и определении метрик успеха. Его также можно вызвать напрямую:

```text
Используй $seven-action-documentation для аудита нашей документации по адаптации пользователей.
```

Skill помогает агенту определить основное действие читателя, выбрать полезные типы контента, а также сформулировать ожидаемый результат и способ его измерения, не выдумывая факты о продукте.
